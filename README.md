## 📌 Featured Projects

### 🌦️ Interconnected Automatic Weather Station — *Undergraduate Thesis*

> University of San Carlos &nbsp;|&nbsp; Localized Microclimate Monitoring

An offline-first weather-monitoring system designed to collect, transmit, archive, and display localized meteorological observations without relying on cellular service or cloud infrastructure.

- **Sensor nodes:** Two Heltec WiFi LoRa 32 V3 boards with ESP32-S3 and SX1262 radios
- **Measurements:** Temperature, relative humidity, barometric pressure, wind speed, wind direction, and rainfall
- **Telemetry:** Direct LoRa communication with staggered transmission slots and ten-minute batch delivery
- **Base station:** Raspberry Pi running Python services with local SQLite storage
- **Interface:** Local browser dashboard, recent-history graphs, node diagnostics, and CSV export
- **Weather outlook:** Experimental 12-to-24-hour Zambretti outlook based on corrected pressure trends and wind direction
- **Reliability:** Sequence tracking, packet-integrity checks, RSSI/SNR logging, automated quality control, and planned store-and-forward recovery

### 📚 JusBooks — *Online Secondhand Textbook Marketplace*

> CPE 2201 Project &nbsp;|&nbsp; University of San Carlos

A full-stack platform for students to buy and sell secondhand textbooks.

- **Backend:** Node.js, Express.js, SQLite, JWT authentication, and Nodemailer with Gmail OAuth2
- **Frontend:** Vanilla HTML/CSS and modular JavaScript
- **Payments:** PayPal sandbox integration with GCash and Maya placeholders
- **Team:** Axel, Darrell, Kent, and Oliver
